# Fleet Guardian

Preciso de um sistema para controle de manutenção de frotas, são 7 veiculos, preciso que sejá editável, que possa adicional ou remover mais veiculos, histórico de manutenções.
Alguns dados importantes para por: Data, veiculo, descrição do serviço, valor, km (apenas algumas ideias, pode ser mais completa)

O sistema pode ter dashboards para resumo sobre os veiculos, sendo possível por a imagem dos carros e placa para melhor identificação
